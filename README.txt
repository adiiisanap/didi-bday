DIDI BIRTHDAY WEBSITE — QUICK SETUP

Files:
- index.html
- style.css
- script.js
- assets/ (make this folder for your media)

PERSONALIZE:
1. Open script.js.
2. Change const DIDI_NAME = "Didi"; to her name.
3. Put her photo at assets/didi-photo.jpg (JPG recommended).
4. Put a music file you have permission to use at assets/birthday-song.mp3.
5. Open index.html in a browser to test.

MUSIC:
The music button intentionally requires a click. Browsers commonly block autoplay.
Use an MP3 you own or have permission to use.

GITHUB PAGES:
1. Create a GitHub repository.
2. Upload index.html, style.css, script.js, and the assets folder.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait for GitHub Pages to publish the site.

The page uses Google Fonts when online; fallback fonts work offline too.
